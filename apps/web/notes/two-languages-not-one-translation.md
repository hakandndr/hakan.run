title: Two languages, not one translation

TürkiyeCennet serves Turkish and English pages for the same places. It would have been easy to treat one page as source text and the other as its translation. I chose a different boundary: coordinates, sources, images and place identity are shared; the editorial prose is written for each reader.

An English visitor may need context that a local reader already has. A Turkish reader may need local names and practical detail that would be flattened by sentence-for-sentence translation. The two pages can therefore describe the same verified place without being identical pieces of copy.

This costs editorial time. A place is not ready merely because its facts exist; both language pages need to be written and checked. The shared facts keep the routes aligned while the prose is allowed to diverge.

Community records later needed a different language rule: visitor text stays in the language supplied, while the surrounding place-page interface changes. That is mutable visitor content, not a second version of the editorial prose.
